Field intel

This is a working pre-release prototype for Modern Warfare 4. The catalog contains the 22 named beta weapons. Axion, Sang 9mm and Wz. 55 Striga still lack recovered standard attachment lists. PILA and Combat Knife have no beta Gunsmith. This is not a complete final launch or live Warzone inventory.

The builder now contains 995 standard weapon–attachment entries across 17 weapons, recovered from AzerPUG’s community beta catalog and compared with CODMunity and WZRanked. Shared attachments appear under each compatible weapon. Final live MW4 Warzone compatibility, attachment conflicts and conversion-specific options remain unverified. Sample mode uses fictional test names.

Apex names are available as a separate reference and cannot be selected into the five standard slots. Weapon images show the base weapon from official beta promotional artwork. Selecting attachments updates the kit list; it does not change the pictured model.
